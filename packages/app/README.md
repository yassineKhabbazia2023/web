# Introduction 

The `@pulse/app` project is a Vue 3 Single Page Application (SPA) that organizes the libraries, applets, and external packages of the Pulse Front. It originated from the [KPMG.Pulse.Front.Router](https://kpmgfr.visualstudio.com/Constellation/_git/KPMG.Pulse.Front.Router) project.

# Getting Started

The initialization process is managed at the root of the monorepo using npm’s `workspaces` feature. Please refer to the [root README](../../README.md) for instructions on installing all dependencies and getting started.

To start the development server and launch the full application, run:

```
npm run dev
```

# Build and Test

The application is built using [Vite](https://vitejs.dev/).
To build the application, use:

```
npm run build
```

To preview the built application, run:

```
npm run preview
```

To run tests, use:

```
npm run test
```
